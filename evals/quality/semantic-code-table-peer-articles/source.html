Primary API reference

The grouped query keeps values numeric while it combines rows by team.

Build the grouped result

result = frame.group_by("team").agg(
    total=pl.col("value").sum(),
    average=pl.col("value").mean(),
)

Result columns

ColumnMeaning
teamThe grouping key.
totalThe sum of values.
filtered = result.filter(pl.col("total") > 10)
