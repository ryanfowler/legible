Working with grouped data

Grouped data lets a report compare several measurements without copying the source rows.

The examples below use the same input table and preserve the original column names.

Create a grouped result

result = frame.group_by("team").agg(
    total=pl.col("value").sum(),
    average=pl.col("value").mean(),
)

The grouped result contains one row for each team and keeps the aggregate values numeric.

Result columns

ColumnMeaning
teamThe grouping key from the source data.
totalThe sum of values in the group.
averageThe arithmetic mean of values in the group.

Filter the result

filtered = result.filter(pl.col("total") > 10)

Filtering after aggregation keeps the operation readable and avoids changing the input frame.
