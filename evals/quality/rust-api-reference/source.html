Method Buffer::reserve

pub fn reserve(&mut self, additional: usize)

Reserves capacity for at least additional bytes without changing the current length.

The buffer can reserve more space than requested to reduce future allocations. Callers must not depend on the exact resulting capacity. Existing bytes and their order remain unchanged when storage moves.

Use this method when the next write size is known and allocation failure can follow the normal panic policy. Use the fallible reserve method when input can request untrusted or unusually large buffers.

Panics

Panics if the new capacity exceeds isize::MAX bytes.

The allocator can also abort or panic when it cannot satisfy the request. Validate protocol length fields before converting them into a reservation size.

Example

let mut data = Buffer::new();
data.reserve(32);

The example reserves once before a sequence of small writes. Repeated calls are valid, but calculating the complete upcoming size usually gives the allocator better information.
