Consume a text stream

Decode each chunk with streaming mode enabled so split Unicode sequences remain valid.

Network chunk boundaries do not match character boundaries. A single UTF-8 sequence can begin at the end of one chunk and finish in the next. Decoding every chunk independently replaces that character with an error marker even though the complete byte stream is valid.

Create one decoder for the full response. Streaming mode tells the decoder to retain an incomplete trailing sequence. Append each decoded string to the destination or send it to a parser that can also accept partial input. 

const decoder = new TextDecoder();
for await (const chunk of source) {
  output += decoder.decode(chunk, { stream: true });
}

Flush the decoder

Call the decoder once without a chunk after the source closes. This flushes buffered bytes and reports an incomplete final sequence. Do not create a second decoder for this step because it cannot see the bytes retained by the first instance. 

output += decoder.decode();

When malformed input must stop processing, construct the decoder with the fatal option. Catch the resulting exception at the boundary that owns the response so the application can close files, cancel related work, and report which stream failed.

Test with chunk sizes of one byte as well as normal transport sizes. Include characters that use two, three, and four bytes. The output must match decoding the same bytes in one complete buffer.
